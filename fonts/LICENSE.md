# Font sources and licences

The `.ttf` files in this folder are generated by `tools/build_fonts.py`. Each glyph is the original bitmap re-expressed as 1×1 pixel squares, so it renders pixel-for-pixel at its native size. Rebuild them with:

```sh
python3 -E tools/build_fonts.py <wine/fonts dir> <font_8x16.c> fonts [<liberation-fonts-ttf dir>]
```
